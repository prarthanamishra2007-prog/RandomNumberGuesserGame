# Random Number Guesser Game 🎯

A simple Java console game where the computer picks a number from 1 to 100 and you try to guess it.

## Features
- Hints after each guess: too high or too low
- Rejects numbers outside 1–100
- Shows total attempts, invalid attempts, and real attempts at the end

## How to run
1. Open `Main.java` in VS Code or any Java IDE
2. Run it, and type your guesses in the console

## What I learned
Loops (do-while), if/else conditions, user input with Scanner, and debugging.
